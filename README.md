# Student Performance Data Analysis

Data Analysis Project 1 - University of Prishtina

## Project Description
Descriptive statistical analysis and linear regression
modeling of student academic performance using Python.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels
- Jupyter Notebook

## Dataset
Student Performance dataset (`data/student-mat.csv`) from the UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/320/student+performance

Cortez, P. (2008). Student Performance [Dataset]. DOI: 10.24432/C5TG7T

## Project Files
- `analysis.ipynb`: code, results and figures
- `data/student-mat.csv`: dataset
- `reports/Raporti_Projekti_1_Data_Analysis_FINAL.pdf`: technical report

## How to Run
```bash
python -m pip install -r requirements.txt
```

Then open `analysis.ipynb` and run all cells.
